🛡️ Section 5: Phase 4 — 安全加固与前端界面

JWT 认证 · 审计日志 · 脱敏 · Web 聊天界面

5.1 安全加固清单

安全实现方案
JWT 认证
  • 基于已实现的 common/auth.py
  • RS256 签名（公私钥分离）
  • Access Token 15min + Refresh Token 7d
  • 角色注入: admin/rd/quality/regulation/sales
  • 部门注入: dept_mask 位运算
审计日志
  • 记录: user_id, query_hash, 过滤表达式, 拦截原因
  • 查询脱敏: user_query → SHA256
  • 配方查询: [REDACTED] 替代敏感内容
  • 存储: 结构化 JSON → Elasticsearch
  • 保留: 180 天 (合规要求)
传输安全
  • HTTPS (TLS 1.3) — 通过 Nginx 反向代理
  • CORS 白名单 (非 *)
  • Rate Limiting: 法规 60%, 研发 30%, 闲聊 10%
  • 请求大小限制: 10KB/query
数据安全
  • MinIO 文档: 临时签名 URL (60s 有效)
  • 端点内权限重校验 (is_allowed)
  • Redis 密码 + TLS
  • 环境变量敏感值加密

5.2 前端 Web 界面

Web UI 方案选型
✅ 推荐: React + Chat UI Kit
  • 基于 chatui / ChatGPT-Next-Web 魔改
  • 多轮对话 + Markdown 渲染
  • 权限切换 (角色选择器)
  • 引用溯源展示
  • 响应式设计
备选: 纯 Streamlit
  • 开发速度最快
  • 功能受限
  • 不适合生产环境
  • 仅适合内部工具

5.3 用户管理

  • 用户注册/管理：基于 SQLite/PostgreSQL 的用户表，存储 role_mask + dept_mask
  • 角色分配：管理员通过 Web UI 分配角色和部门
  • LDAP 集成（可选）：对接企业已有的 AD/LDAP 认证
  • 会话管理：6 轮对话上下文，session_id 关联用户身份

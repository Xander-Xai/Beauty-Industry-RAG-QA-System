3.2 端到端测试场景

基础场景 (20 条)
  • 单轮成分查询："烟酰胺的安全浓度是多少？"
  • 单轮法规咨询："化妆品中铅含量限制是多少？"
  • 通用产品查询："XX 品牌的保湿霜含哪些成分？"
复杂场景 (20 条)
  • 多轮对话：追问问法规适用范围
  • 跨域问题：成分安全性 + 法规限制综合
  • 模糊意图："这个东西能用吗？"
  • 图像相关："包装上这个标识是什么意思？"
边界场景 (15 条)
  • 知识库无覆盖的领域外问题
  • 权限受限用户查询受限文档
  • 超长输入（>2000 字符）
  • 并发 20 条同时请求
降级场景 (10 条)
  • Rewrite 失败 → 规则兜底
  • Milvus 不可用 → ES Fallback
  • KV 压力 > 90% → 降级输出
  • Redis 不可用 → L1 仅模式

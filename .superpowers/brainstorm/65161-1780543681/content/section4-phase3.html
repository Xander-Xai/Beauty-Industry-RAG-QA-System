4.1 Docker Compose 架构优化

docker-compose.yml 重构方案
docker-compose.yml          # 主编排文件
docker-compose.gpu.yml      # GPU 服务覆盖 (双卡)
docker-compose.cpu.yml      # CPU 降级覆盖 (开发)
.env                        # 环境变量 (从 .env.example 复制)

services:
  app:                      # FastAPI 主应用
  redis:                    # L1/L2 缓存
  milvus-standalone:        # 向量数据库
  elasticsearch:            # BM25 全文检索
  minio:                    # 文档对象存储
  etcd:                     # Milvus 依赖

  # GPU 服务 (仅 docker-compose.gpu.yml)
  vllm-gen-14b:             # GPU0: 复杂生成
  vllm-gen-4b:              # GPU1: 简单生成
  vllm-rewrite:             # GPU1: Query Rewrite

4.3 一键启动流程

启动脚本 scripts/start.sh
$ ./scripts/start.sh --mode testing

Step 1/6  检查环境 (Docker, nvidia-smi)     ✅
Step 2/6  检查模型权重完整性                 ✅ 8/8 模型就绪
Step 3/6  初始化向量库 Schema                ✅ rag_text_768, rag_image_512
Step 4/6  导入 Mock 数据 (首次)              ✅ 287 文档, 102 图像
Step 5/6  启动基础设施 (Redis/Milvus/ES)     ✅ 等待健康检查通过
Step 6/6  启动应用服务                       ✅ http://localhost:8000

系统就绪 🚀

4.4 健康检查完善

检查项 端点 超时 失败行为
Redis 连接 GET /health/redis 2s 降级到 L1 内存缓存
Milvus 连接 GET /health/milvus 3s 切换 ES Fallback
ES 连接 GET /health/es 3s BM25 路径降级
vLLM 就绪 GET /health/vllm 30s 启动阶段等待；运行阶段 503
GPU 可用性 nvidia-smi 5s 自动降级到 CPU 模式

# 化妆品知识问答系统 — 用户手册

## 功能简介

本系统为化妆品企业提供智能知识问答，支持：
- **成分查询**: 查询化妆品成分的安全浓度、法规限制、功效信息
- **法规咨询**: 查询各类化妆品法规标准、检测方法、合规要求
- **配方研发**: 了解配方组成、成分搭配、工艺建议
- **产品信息**: 查询产品成分表、保质期、使用方法

## 快速开始

### 访问系统

打开浏览器，访问 `http://localhost:8000`（或管理员提供的地址）。

### 选择身份

左侧边栏可选择不同角色，不同角色可以访问不同范围的文档：
- **研发人员**: 可访问配方、成分等研发文档
- **品质人员**: 可访问检测标准、质量规范
- **法规人员**: 可访问法规、标准、公告
- **销售人员**: 可访问产品信息、公开法规

### 提问方式

1. 在底部输入框输入问题
2. 点击"发送"或按 Enter
3. 系统会自动检索相关文档并生成回答
4. 回答下方会显示参考来源和耗时

### 示例问题

- "烟酰胺的安全浓度是多少？"
- "化妆品中铅含量的限量标准是什么？"
- "水杨酸在驻留型产品中的最大允许浓度？"
- "防晒产品需要哪些法规认证？"

### 多轮对话

支持上下文追问：
1. 先问："化妆品中铅含量的限量标准是什么？"
2. 再追问："这个标准适用于哪些产品类型？"
3. 系统会理解上下文，给出连贯的回答

## 注意事项

- 系统仅能查询**已录入知识库**的内容
- 回答仅供参考，重要法规/安全决策请以官方文件为准
- 配方相关问题的回答基于知识库中的已有配方，不代表推荐配方

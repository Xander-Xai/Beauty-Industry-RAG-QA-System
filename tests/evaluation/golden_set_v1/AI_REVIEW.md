### 2.1 斜杠 `/` 的真实含义（本轮实测得出）

本语料 127 行 × 2 列共 254 个用量单元格中：

| 单元格取值 | 次数 |
|---|---|
| `/` | 110 |
| `未提供` | 63 |
| 具体数值 | 81 |

**关键发现：`/` 与"备注"栏是 110/110 完全共现的。** 所有两列均为 `/` 的行，其备注
必然是 `按照《化妆品安全技术规范》要求使用`（54 行）或 `《化妆品安全技术规范》禁用组分`
（1 行），合计 55 行 × 2 列 = 110，与 `/` 的总数**精确相等**；而 `未提供` 行的备注一律是
`未提供`。

因此在本语料内，`/` 的含义是：**本目录不给数值，该原料的使用由《化妆品安全技术规范》
管辖**——它既不是"无限量"，也不是"未提供数值"这个中性地毯式表述。

需要注意：目录说明九条写的是"对目录**未提供**最高历史使用量的原料……"，字面对应的是
`未提供` 而非 `/`。**语料本身没有定义 `/`**，上面的结论是由 110/110 的共现模式推得的，
不是目录明文规定。任何把 `/` 的语义当作明文引用来写的答案都超出了语料本身。

## 3. 需要人工裁定的争议项

### 3.1 REAL-V1-002：第四条与第十七条同为 relevance=2 — **成立，保留**

第四条原文"国家对特殊化妆品实行注册管理，对普通化妆品实行备案管理"**独立完整**回答该问；
第十七条"特殊化妆品经……注册后方可生产、进口。国产普通化妆品应当在上市销售前向……备案"
同样**独立完整**回答该问。二者都是真正的 rel=2，不是"信息更多"的 rel=1。

代价是双金标下 `Recall@1` 理论上限 0.5。这是 TREC 多相关文档的标准口径，
`README.md` 第 1 节已经写明，**不是缺陷，也不应为了保住数字而删掉一篇**。

### 3.2 REAL-V1-018 / 019 / 020 — **成立，保留为改写探针**

三条与 001/003/010 共用金标，但差异是真实的，不是复制：

| 样本 | 与基准的差异维度 |
|---|---|
| 018 vs 001 | 语域：`是怎么定义的`（口语） vs `法定定义`（法条语域） |
| 019 vs 003 | 说话人：申请人视角 `给……办` vs 抽象陈述 `在什么情况下` |
| 020 vs 010 | 术语：`冲洗` vs 目录用词 `淋洗`；且只问数值，不问 INCI 名 |

共享金标**正是改写鲁棒性探针的定义**，不是近重复的证据。若删除它们，本 V1 将失去
唯一的"同义改写"能力覆盖。三条均已带 `query_family` 标注，且有测试固定。

### 3.3 REAL-V1-021：第四条 relevance=1 — **⚠️ 与 README 第 5 节口径冲突，建议人工裁定**

问题：`企业使用已列入目录的原料生产国产普通化妆品，需要办理哪些注册和备案手续？`

- 第十七条：`国产普通化妆品应当在上市销售前向备案人所在地省、自治区、直辖市人民政府
  药品监督管理部门备案。` → **单独完整回答**，rel=2 正确。
- 第四条：`国家对特殊化妆品实行注册管理，对普通化妆品实行备案管理。` →
  **不能单独回答"需要办理哪些手续"**（无时间、无机关、无程序）。

按 `README.md` 第 5 节"relevance=1 是**缺了它答案就不完整**，不是信息更多"这一条：
删掉第四条**答案依然完整**，因此第四条应判为 **0（已考虑并排除）**而非 1。

**反向理由（支持保留 rel=1）**：第四条是唯一说明"普通化妆品只需备案、无需注册"的条文，
补上了第十七条未明说的那一半。

**AI 建议：改判为 relevance=0 并保留在行内**（计入"已考虑并排除"，可审计），
以与 README 自己的口径一致。**但这是标注判断，交由具名审核人裁定，AI 不自行改写。**

### 3.4 REAL-V1-025：`/` 与"未给数值 ≠ 无限制" — **证据充分，保留**

问题分两问：(a) 苯甲醇驻留类是否给出数值；(b) 未给数值是否等于无限制使用。

- (a) 金标行 `序号01279` 两列均为 `/` → 直接可读，✅
- (b) **同一行**的备注为 `按照《化妆品安全技术规范》要求使用` → 该表述本身即说明

因此该行**单篇即可回答两问**，不需要额外法规依据，也不需要靠常识补金标。

但**不是**回答该问所必需的第二金标。

## 4. 3 条 Answer Gate 复核

| 样本 | 问题 | 语料内证据核查 | AI 判定 |
|---|---|---|---|
| NOANSWER-001 | 铅的限量 mg/kg | 全语料 **0 次**出现"铅"，0 次出现"限量"、0 次出现"mg/kg" | ✅ 确实无证据，`refuse` 正确 |

| NOANSWER-003 | 甲醇限量 | "限量" 0 次；"甲醇" 0 次作为独立成分 | ✅ 确实无证据，但见下 |

### 4.1 NOANSWER-002 的 `expected_behavior` 应调整

该问题的正确行为**不是纯拒答**。语料能给出**部分且正确**的回答：

> "《已使用化妆品原料目录（2021年版）》中烟酰胺（序号07359）的淋洗类与驻留类
> 最高历史使用量均记载为'未提供'。'最高允许浓度'是《化妆品安全技术规范》的限量概念，
> 不在本条例与该目录内。"

因此 `expected_behavior` 建议由 `refuse` 改为 **`partial_answer_and_state_gap`**（回答部分
并说明缺口）。当前 `refuse` 会把一个本可给出正确部分回答的系统判为失败。

### 4.2 NOANSWER-003 存在关键词假阳性（对样本有利）

`苯甲醇`（BENZYL ALCOHOL，序号01279）**包含"甲醇"子串**。单字检索 `甲醇` 会命中它，
但苯甲醇 ≠ 甲醇。说明该样本**不只**测关键词未命中，还测语义区分——这是优点，
但现有 note 只写"No chunk contains any searched token pair"，**低估了难度**。
建议在 note 中补记这一语义干扰项。

### 4.3 未混入分母（已验证）

3 条 `no_answer` 样本位于独立文件 `no_answer_candidates_v1.jsonl`，
`evaluation_target: answer_gate`，不含 `annotations`，**不参与 Retrieval Recall 分母**。✅

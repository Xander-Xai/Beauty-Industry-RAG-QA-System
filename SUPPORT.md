# Support

This repository is a community-maintained engineering reference, not a hosted service or a support contract. There is no guaranteed response time or service-level agreement.

- For reproducible defects, use the [Bug Report issue form](https://github.com/Xander-Xai/Beauty-Industry-RAG-QA-System/issues/new?template=bug_report.yml).
- For documentation corrections, use the [Documentation issue form](https://github.com/Xander-Xai/Beauty-Industry-RAG-QA-System/issues/new?template=documentation.yml).
- For feature proposals, use the [Feature Request issue form](https://github.com/Xander-Xai/Beauty-Industry-RAG-QA-System/issues/new?template=feature_request.yml).
- For evaluation results or reproduction problems, use the [Evaluation / Reproduction issue form](https://github.com/Xander-Xai/Beauty-Industry-RAG-QA-System/issues/new?template=evaluation_reproduction.yml).
- For vulnerabilities, follow [SECURITY.md](SECURITY.md); do not include sensitive details in a public issue.

Before opening an issue, check the [documentation index](docs/README.md) and existing [issues](https://github.com/Xander-Xai/Beauty-Industry-RAG-QA-System/issues). Include repository SHA, exact command and redacted logs when relevant. Never attach credentials, private corpora or personal data.
